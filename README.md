# Hangman Game

A simple command-line Hangman game written in Python. Guess the hidden word one letter at a time before you run out of attempts.

## Requirements

- Python 3

## Run the game

From this repository folder, run:

```powershell
python "hangman game.py"
```

## How to play

1. Start the game to reveal the hidden word as underscores.
2. Enter one letter per guess.
3. Correct guesses reveal matching letters. Each incorrect guess uses one of your six attempts.
4. Guess the whole word before your attempts run out to win.

The word is selected at random from a small built-in list. No additional packages are required.
